# TeacherTown 디자인 가이드

`app/globals.css`에 실제로 구현된 디자인 토큰과 화면 구성을 정리한 문서다. 새 화면을 만들 때
이 문서의 토큰과 컴포넌트 클래스를 재사용한다.

## 컨셉

승인된 교사만 들어오는 폐쇄형 공간에서, 학교 근무경험이 아니라 **나눔·소모임·학교정보**
세 가지를 중심으로 신뢰 가능한 정보를 쌓는다. 톤은 따뜻하고 차분하게 — 채도 높은 그라디언트나
게이미피케이션 요소 없이, 정보 밀도를 낮추고 여백을 넉넉히 둔다.

- 모바일 퍼스트, 최대 폭 480px로 데스크톱에서도 앱처럼 보이게 고정한다.
- 4개 탭 하단 네비게이션: **나눔 / 소모임 / 학교정보 / 내설정**.
- 관리자 화면(`/admin/*`)은 별도 톱 네비게이션을 쓰는 얇은 레이아웃으로 분리한다.

## 컬러 토큰 (`:root` 변수)

| 변수 | 값 | 용도 |
| --- | --- | --- |
| `--color-bg` | `#faf7f2` | 페이지 배경. 따뜻한 아이보리 |
| `--color-surface` | `#ffffff` | 카드·입력창·헤더 배경 |
| `--color-border` | `#ece3d8` | 카드 테두리, 구분선 |
| `--color-text` | `#2b2620` | 본문 텍스트 |
| `--color-text-muted` | `#79726a` | 보조 텍스트, 메타 정보 |
| `--color-accent` | `#ff7a30` | 브랜드 강조색(주황). 버튼, 활성 탭, 태그 |
| `--color-accent-weak` | `#ffe8d9` | accent의 옅은 배경 (태그, 통계 박스) |
| `--color-danger` | `#d64545` | 거절·삭제 등 위험 액션 |
| `--color-success` | `#3a8f5b` | 나눔중 태그 등 긍정 상태 |
| `--radius` | `14px` | 카드 기본 모서리 반경 |
| `--nav-height` | `60px` | 하단 네비게이션 높이 |

그라디언트는 쓰지 않는다. 강조는 색 하나(주황)와 여백으로만 만든다.

## 레이아웃 구조

```
.page            페이지 전체 컨테이너. max-width 480px, 하단 네비 높이만큼 padding-bottom
.header          상단 고정 헤더. 16px 굵은 타이틀, sticky top
.container       본문 좌우 여백 16px
.bottom-nav      4칸 grid 하단 네비게이션. 아이콘 + 라벨, 활성 탭만 accent 색
```

## 컴포넌트 클래스

- **`.card`** — 흰 배경, 옅은 테두리, 살짝의 그림자(`0 1px 2px rgba(0,0,0,.03)`). 목록의
  게시글 카드, 통계 박스, 폼 래퍼로 재사용한다.
- **`.tag`** / **`.tag-available` / `.tag-reserved` / `.tag-completed`** — 나눔 글 상태
  배지. 나눔중(초록 계열), 예약중(황토), 나눔완료(회색)로 색만 다르고 모양은 통일한다.
- **`.btn`** — 폭 100%, accent 배경의 기본 버튼. `.btn-secondary`(흰 배경+테두리),
  `.btn-danger`(거절 등)로 변형한다.
- **`.field`** — label + input 세트. 라벨은 13px 회색 볼드, input은 10px 라운드에
  1px 테두리.
- **`.stat-box`** — accent-weak 배경의 큰 숫자 강조 박스. 누적 탄소량, 학교 전체 평균에 쓴다.
- **`.stars` / `.star-btn`** — 학교 평가 별점 입력. 채워진 별만 accent 색.
- **`.rating-row`** — 질문 텍스트 좌, 점수/평균 우 배치. 구분선으로 리스트를 이룬다.
- **`.comment`** — 닉네임(볼드) + 본문. 구분선으로 리스트를 이룬다.
- **`.image-grid`** — 2열 정사각형 그리드. 나눔/소모임 상세의 사진을 보여준다.
- **`.filters`** — 가로 스크롤 가능한 select 필터 바. 학교급 → 세부 카테고리 순서로 배치하고,
  학교급을 고르지 않으면 세부 카테고리는 비활성화한다.
- **`.empty`** — 목록이 비었을 때 가운데 정렬된 안내 문구.

## 화면별 적용 (실제 라우트)

| 화면 | 경로 | 핵심 요소 |
| --- | --- | --- |
| 나눔 목록 | `/share` | 필터 바 + 상태 태그가 붙은 카드 목록 + "나눔 글쓰기" 버튼 |
| 나눔 상세 | `/share/[id]` | 상태 태그, 2열 사진 그리드, 예약/취소/완료 액션, 댓글(예약중 비활성화) |
| 나눔 글쓰기 | `/share/new` | 학교급→카테고리 종속 select, 품목 유형 select(탄소량 자동 표시), 사진 1~4장 |
| 소모임 목록/상세/작성 | `/clubs*` | 나눔과 동일한 카드·필터 패턴, 상태 태그 없음, 사진 0~2장 |
| 학교정보 검색 | `/schools` | 단일 검색창 + 결과 카드 목록 (지도 없음) |
| 학교 상세 | `/schools/[id]` | `.stat-box`로 전체 평균 강조 → 질문별 `.rating-row` → 별점 입력 카드 |
| 내설정 | `/me` | 누적 탄소량 `.stat-box` → 프로필 폼 카드 → 내가 쓴 나눔/소모임 글 목록 |
| 관리자 승인 | `/admin/approvals` | 신청자 카드(이메일·성함·학교·신청일) + 승인/거절 버튼 |
| 관리자 질문 관리 | `/admin/questions` | 추가 폼 + 질문별 활성/비활성 토글 카드 |

## 타이포그래피

시스템 폰트 스택(`-apple-system, "Segoe UI", "Apple SD Gothic Neo", "Noto Sans KR"`)만
쓰고 별도 웹폰트는 로드하지 않는다. 제목은 17~24px/700, 본문은 15px/400, 메타 정보는
13px/400 회색(`--color-text-muted`)으로 위계를 나눈다.

## 이번 스코프에서 의도적으로 뺀 것

- 비밀게시판(익명 게시판), 학교 리뷰의 "5개 이상 통계 공개" 임계치, 지도 렌더링, 인디스쿨식
  자료공유 — 모두 `prd.md`의 Non-Goals에 명시되어 이번 MVP 디자인에 넣지 않았다.
- 랭킹·배지·등급 UI. 탄소량은 본인만 보는 숫자 하나로만 표시한다.
